## SJE PR Edit Pro (UXP)

Adobe Premiere Pro용 UXP 플러그인. 자막 기반 영상 편집 작업을 자동화합니다.

### 주요 기능

**Edit Pro 탭**
- 슬라이드 마커 추가 (`[Slide N]`)
- 앵글 태그 추가 (정면 / 좌측 / 우측)
- 이미지 번호 마커 추가 (`[#N]`)
- 앵글 자동 스위칭 (마커 기반)
- 이미지 자동 배치 (마커 기반)

**Stack Images 탭**
- 이미지 쌓기 — 선택한 이미지를 지정 V트랙부터 순서대로 쌓기
- 음성+이미지 나열 — 음성 파일과 매칭 이미지를 파일명 기준으로 자동 배치

### 설치 방법
1. `SJE_PR_Edit_Pro_UXP` 폴더를 다운로드
2. Adobe UXP Developer Tool에서 플러그인 로드
3. 또는 `.ccx` 파일 더블클릭으로 자동 설치

### 라이선스
- 체험판: 이메일 인증 후 7일 무료 사용
- 구독: 월간 / 연간 라이선스 키 입력 후 사용

### 요구사항
- Adobe Premiere Pro 25.6 이상 (UXP 지원 버전)
