# SJE AE Copy-Paste Pro

Adobe After Effects용 CEP 플러그인. 레이어 복사/붙여넣기 작업을 자동화합니다.

---

## 주요 기능

- 레이어 Copy-Paste 자동화
- 하드웨어 기반 라이선스 시스템 (Google Sheets 서버)
- 체험판 및 구독 라이선스 지원

---

## 파일 구성

| 파일 | 설명 |
|---|---|
| `SJE AE Copy-Paste Pro.jsx` | 플러그인 소스 코드 |
| `AE SJE Copy-Paste Pro.jsxbin` | 배포용 난독화 바이너리 |
| `AE_License.py` | 라이선스 생성 도구 (소스) |
| `AE_License.exe` | 라이선스 생성 도구 (실행파일) |
| `Install AE SJE Copy-Paste Pro.bat` | 설치 배치 파일 |
| `Google_Apps_Script_License_Server_REVISED_v3.gs` | 라이선스 서버 (Google Apps Script) |

---

## 설치 방법

1. `Install AE SJE Copy-Paste Pro.bat` 실행
2. After Effects 재시작
3. 메뉴 → Window → `SJE AE Copy-Paste Pro` 패널 열기

---

## 라이선스

- 체험판: 이메일 인증 후 7일 무료 사용
- 구독: 라이선스 키 입력 후 사용
- 라이선스 저장 경로: `Documents/CopyPastePro/license.key`

### 요구사항
- Adobe After Effects (CEP 지원 버전)
