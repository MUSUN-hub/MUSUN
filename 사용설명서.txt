이 프로그램은 Claude AI와 Adobe Premiere Pro를 연결해서
영상 편집을 자동으로 해주는 도구입니다.

예를 들면:
  - "타임라인에서 5초~20초 구간을 잘라줘"
  - "NG 장면 자동으로 찾아서 삭제해줘"
  - "빈 공간 전부 없애줘"
같은 말을 Claude에게 하면 Premiere Pro가 자동으로 편집을 진행합니다.

【 2단계. 필수 프로그램 설치 】

이 도구를 사용하려면 아래 프로그램들이 컴퓨터에 설치되어 있어야 합니다.

─────────────────────────────────────────────
[2-1] Python 설치 확인 및 uv 설치
─────────────────────────────────────────────

① 먼저 "uv" 라는 Python 패키지 관리 도구를 설치합니다.
   키보드에서 Windows 키 + R 을 누르고 "powershell" 입력 후 확인.

② PowerShell(검은 창)이 열리면 아래 명령어를 복사해서 붙여넣기:

   winget install --id=astral-sh.uv -e

   엔터를 누르면 자동으로 설치됩니다.

③ 설치가 끝나면 창을 닫고 다시 PowerShell을 열어서 아래 명령어로 확인:

   uv --version

   버전 번호가 나오면 성공입니다. (예: uv 0.5.x)

─────────────────────────────────────────────
[2-2] MCP 라이브러리 설치
─────────────────────────────────────────────

PowerShell에서 아래 명령어 실행:

   uv pip install mcp --system

"Successfully installed mcp-..." 같은 메시지가 나오면 성공입니다.

─────────────────────────────────────────────
[2-3] Adobe Premiere Pro 설치 확인
─────────────────────────────────────────────

Premiere Pro 2022(버전 22) 이상이 설치되어 있어야 합니다.
CEP 기능을 사용하려면 버전 14(Premiere Pro 2020) 이상이면 됩니다.

【 3단계. CEP 플러그인 설치 】

CEP 플러그인은 Premiere Pro에서 ExtendScript(고급 편집 명령)를 실행해 주는
패널입니다. razor(컷 넣기), NG 구간 삭제 기능에 필수입니다.

─────────────────────────────────────────────
[3-1] cep_plugin 폴더를 Premiere Pro 플러그인 폴더에 복사
─────────────────────────────────────────────

① 이 패키지 안의 "cep_plugin" 폴더 전체를 복사합니다.

② 아래 경로로 이동합니다. (탐색기 주소창에 그대로 붙여넣기)

   %APPDATA%\Adobe\CEP\extensions

   ※ %APPDATA% 는 보통 C:\Users\[내 이름]\AppData\Roaming 을 의미합니다.
   ※ "extensions" 폴더가 없으면 직접 만들어도 됩니다.

③ "extensions" 폴더 안에 "cep_plugin" 폴더를 붙여넣습니다.
   폴더 이름을 "SJECEPBridge" 로 바꿔주세요.

   최종 경로 예시:
   C:\Users\홍길동\AppData\Roaming\Adobe\CEP\extensions\SJECEPBridge\

─────────────────────────────────────────────
[3-2] 레지스트리 설정 (개발자 모드 활성화)
─────────────────────────────────────────────

Adobe CEP 플러그인을 직접 설치하려면 "개발자 모드"를 켜야 합니다.

★ 가장 쉬운 방법 — .reg 파일 더블클릭 (강력 추천)

이 패키지 안에 "레지스트리_개발자모드_활성화.reg" 파일이 있습니다.

① 그 파일을 더블클릭합니다.
② "이 파일을 레지스트리에 추가하시겠습니까?" 창이 뜨면 "예" 클릭
③ "성공적으로 추가되었습니다" 메시지가 나오면 완료!

  이 파일 하나로 Premiere Pro 모든 버전(2020~2025)에 대해
  개발자 모드가 한 번에 설정됩니다. 버전을 신경 쓸 필요 없습니다.

─────────────────────────────────────────────
[3-3] Premiere Pro 재시작
─────────────────────────────────────────────

Premiere Pro가 열려 있으면 완전히 종료하고 다시 켜주세요.

재시작 후 메뉴에서:
   Window (윈도우) → Extensions (확장) → SJE CEP Bridge

클릭하면 패널이 열리고 자동으로 "Connected" 상태가 됩니다.
패널 안에 초록색으로 "Connected — ..." 라고 나오면 성공입니다.

【 4단계. UXP 플러그인 설치 】

UXP 플러그인은 클립 삽입, 마커 추가, 시퀀스 정보 읽기 등에 사용됩니다.
Premiere Pro 2024 (버전 24) 이상에서 사용 가능합니다.

─────────────────────────────────────────────
[4-1] Adobe UXP Developer Tool 설치
─────────────────────────────────────────────

① 아래 주소에서 Adobe UXP Developer Tool 을 다운로드합니다:
   https://developer.adobe.com/photoshop/uxp/devtool/

② 설치 후 실행합니다. (시작 메뉴에서 "UXP Developer Tool" 검색)

─────────────────────────────────────────────
[4-2] 플러그인 로드
─────────────────────────────────────────────

① UXP Developer Tool 을 실행합니다.
② Premiere Pro도 함께 실행합니다.
③ UXP Developer Tool 에서 왼쪽 상단 "Add Plugin" 버튼 클릭
④ 이 패키지의 "uxp_plugin" 폴더 안의 "manifest.json" 파일을 선택
⑤ 목록에 "MCP Bridge" 가 추가되면 오른쪽의 "Connect" 버튼 클릭
⑥ Premiere Pro 안에 "MCP Bridge" 패널이 열리면 성공

  ※ UXP 플러그인은 매번 Premiere Pro를 켤 때마다
     UXP Developer Tool에서 Connect 를 눌러야 합니다.
     (정식 배포판이 아니기 때문입니다)

【 5단계. MCP 서버 등록 (Claude와 연결) 】

Claude AI가 Premiere Pro를 제어하려면 "MCP 서버"를 등록해야 합니다.

─────────────────────────────────────────────
[5-1] claude.json 파일 찾기
─────────────────────────────────────────────

① 탐색기 주소창에 아래를 입력:
   %USERPROFILE%\.claude.json

   파일이 없으면 새로 만들면 됩니다.

─────────────────────────────────────────────
[5-2] MCP 서버 등록 내용 추가
─────────────────────────────────────────────

.claude.json 파일을 메모장이나 VSCode로 열고
"mcpServers" 항목 안에 아래 내용을 추가합니다.

[유저명] 부분은 본인 Windows 계정 이름으로 바꿔주세요.
[설치경로] 부분은 이 패키지 폴더의 실제 경로로 바꿔주세요.

예시 (파일 전체 내용이 없는 경우):

{
  "mcpServers": {
    "premiere": {
      "type": "stdio",
      "command": "C:/Users/[유저명]/.local/bin/uv.exe",
      "args": [
        "run",
        "--python", "3.14",
        "[설치경로]/mcp_server/premiere_uxp_mcp.py"
      ]
    },
    "premiere-sje-cep": {
      "type": "stdio",
      "command": "C:/Users/[유저명]/.local/bin/uv.exe",
      "args": [
        "run",
        "--python", "3.14",
        "[설치경로]/mcp_server/sje_cep_mcp.py"
      ]
    }
  }
}

실제 입력 예시 (경로가 E:\custom_script\MCP\sje-premiere-mcp 인 경우):

  "command": "C:/Users/kimsj/.local/bin/uv.exe",
  "args": ["run", "--python", "3.14",
           "E:/custom_script/MCP/sje-premiere-mcp/mcp_server/premiere_uxp_mcp.py"]

  ※ 경로에서 역슬래시(\) 대신 슬래시(/)를 사용해야 합니다.
  ※ 기존에 mcpServers 항목이 있으면 { } 안에 추가만 하면 됩니다.

【 5-4. CLAUDE.md — 편집 에이전트 설정 파일 】

이 패키지 안에 "CLAUDE.md" 파일이 있습니다.
Claude Code가 이 파일을 자동으로 읽어서 편집 규칙을 따릅니다.

  ※ Claude Code를 실행할 때 이 패키지 폴더(sje-premiere-mcp)를
     작업 폴더로 열거나, CLAUDE.md를 작업 폴더에 복사해두면 됩니다.

이 파일에는 아래 규칙들이 정의되어 있습니다:

  - NG 판단 기준 (6가지)
      1. 연속 반복 패턴 — 같은 내용을 두 번 말하면 앞이 NG
      2. PD/연출자 개입 — "넘어가 주세요", "다시 해주세요" 등
      3. 재시작 선언 — "다시 하겠습니다", "처음부터" 등
      4. 문장 미완성 끊김 — 말이 중간에서 끊기고 뒤에서 다시 시작
      5. 맥락 단절 잡담 — 강의 흐름과 무관한 짧은 발언
      6. 시간상 떨어진 동일 문장은 별개로 판단 (건드리지 않음)

  - NG 구간 처리 방식
      - razor(컷) → 클립 삭제 → 빈 공간은 사용자 요청 시만 제거
      - 삭제 전 반드시 사용자에게 NG 목록 보고 후 진행

  - 시퀀스 fps 파악 규칙
      - 작업 전 get_sequence_info로 fps 확인
      - 사용자가 HH;MM;SS;FF 형식으로 시간 전달 시 시퀀스 fps 기준으로 변환

  이 파일을 메모장으로 열어 규칙을 직접 수정할 수 있습니다.
  예를 들어 NG 판단 기준을 추가하거나 특정 키워드를 넣으면
  Claude가 자동으로 그 기준에 맞춰 NG를 잡아줍니다.

【 6단계. 매번 사용할 때 하는 순서 】

매일 편집 작업을 시작할 때 아래 순서대로 진행합니다.

  ① Premiere Pro 실행
     └ 프로젝트 파일 열기

  ② CEP 패널 열기
     └ Window → Extensions → SJE CEP Bridge 클릭
     └ 패널에 "Connected" 초록 글씨가 나오면 OK

  ③ UXP 플러그인 연결 (UXP 기능이 필요할 때만)
     └ Adobe UXP Developer Tool 실행
     └ "MCP Bridge" 항목에서 Connect 클릭
     └ Premiere Pro 안에 MCP Bridge 패널이 뜨면 OK

  ④ Claude Code(IDE) 실행
     └ 작업 폴더를 열고 대화 시작

  ⑤ Claude에게 편집 요청
     └ "NG 장면 잘라줘", "5초에서 10초 구간 razor 해줘" 등

【 7단계. Claude에게 말하는 방법 (예시) 】

─────────────────────────────────────────────
[예시 1] NG 장면 자동 삭제
─────────────────────────────────────────────

  사용자: "C0136.srt 파일 읽고 NG 장면 찾아서 삭제해줘"

  Claude가 하는 일:
  1. SRT 파일을 읽어서 자막 분석
  2. 같은 내용을 두 번 말한 구간(앞이 NG) 목록 추출
  3. "이런 NG 구간들이 있습니다. 진행할까요?" 라고 보고
  4. 확인하면 razor로 컷 → 클립 삭제 자동 실행

【 자주 묻는 질문 (FAQ) 】

Q. CEP 패널이 Window → Extensions 메뉴에 안 보여요.
A. 두 가지를 확인하세요:
   ① "SJECEPBridge" 폴더가 %APPDATA%\Adobe\CEP\extensions\ 안에 있는지
   ② 레지스트리에 PlayerDebugMode = 1 이 설정되어 있는지
   둘 다 맞으면 Premiere Pro를 완전히 종료 후 다시 시작하세요.

Q. CEP 패널은 뜨는데 "Connected" 가 안 나와요.
A. 패널 안의 로그에 에러 메시지가 있는지 확인하세요.
   대부분은 %TEMP%\sje-cep-bridge 폴더 접근 문제입니다.
   Windows 탐색기에서 %TEMP%\sje-cep-bridge 폴더를 직접 만들어 보세요.

Q. Claude가 "MCP 서버에 연결할 수 없습니다" 라고 해요.
A. claude.json 파일에서 경로 설정을 확인하세요.
   ① uv.exe 경로가 맞는지 확인: C:\Users\[유저명]\.local\bin\uv.exe
   ② .py 파일 경로가 맞는지 확인 (역슬래시 → 슬래시 변환 필수)
   ③ Claude Code를 완전히 종료 후 다시 시작하세요.

Q. razor는 되는데 클립 삭제가 안 돼요.
A. CEP 패널이 연결되어 있는지 확인하세요.
   클립 삭제는 remove_clips_in_ranges 도구를 쓰는데
   이것도 CEP(SJE CEP Bridge 패널)가 열려 있어야 합니다.

Q. UXP 플러그인은 매번 Connect 눌러야 하나요?
A. 네, 현재 버전은 개발자 모드로 실행되어 매번 눌러야 합니다.
   Premiere Pro를 켤 때마다 UXP Developer Tool → Connect 해주세요.

Q. close_gaps(빈 공간 제거)를 자동으로 하고 싶어요.
A. Claude에게 "붙여줘" 또는 "close_gaps 실행해줘" 라고 말하면 됩니다.
   단, NG 삭제 직후에는 자동으로 실행되지 않습니다.
   (멀티트랙 싱크를 지키기 위해 사용자 확인 후 실행하는 정책입니다)

Q. 작업 중에 실수로 잘못 잘랐어요.
A. Premiere Pro에서 Ctrl + Z 를 여러 번 눌러 되돌릴 수 있습니다.
   MCP 도구가 실행한 작업도 Undo가 됩니다.

Q. SRT 파일이 없는데 NG 삭제를 요청하면 어떻게 되나요?
A. SRT 파일 없이는 NG를 자동으로 찾을 수 없습니다.
   SRT 파일은 영상과 같은 폴더에 같은 파일명으로 있어야 합니다.
   (예: C0136.mp4 → C0136.srt)
